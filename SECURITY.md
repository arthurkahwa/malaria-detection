# Security Policy

## Supported Versions

This is a technology preview. Security fixes are provided on a best-effort basis
for the current `v0.x` line. Older `v0.x` patch releases are not maintained
separately — please update to the latest tag before reporting.

| Version | Supported           |
|---------|---------------------|
| v0.x    | Best-effort         |
| < v0.x  | Not supported       |

## Reporting a Vulnerability

Please report security vulnerabilities **privately**. Do not file public GitHub
issues for security bugs.

- Email: <arthur.kahwa@googlemail.com>
- Expected acknowledgement: within 72 hours

When reporting, please include:

- The affected platform (iOS, Android, or shared module) and version
- A reproduction (steps, sample input, or minimal proof of concept)
- The impact you observed or believe is possible
- Any patches, mitigations, or workarounds you have identified

We will work with you on a coordinated disclosure timeline. Because this
software is not a certified medical device (see `NOTICE`), security issues with
potential safety implications for any clinical deployer will be prioritized.
